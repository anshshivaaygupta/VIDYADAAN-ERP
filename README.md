# 🎓 VIDYADAAN NGO - Free School Education ERP

**विद्यादान (Vidyadaan NGO) - 100% Free & Quality Education Initiative**

Designed specifically for educational NGOs, charitable trusts, and community schools running on the CBSE-aligned curriculum without fees.

---

## 🌟 Key Highlights & Features

1. **🚫 100% Free Education (No Fees)**:
   - All fee collection and billing modules have been completely removed.
   - Tailored specifically for charitable and non-profit educational institutions.

2. **📊 Admin Panel with Full CRUD**:
   - **Student Management**: Add student, edit student, delete single student, or clear all students.
   - **Class & Subject Management**: Add or delete classes and CBSE curriculum subjects.
   - **Attendance Register**: Daily register (Present, Absent, Leave) with "Mark All Present" shortcut.
   - **Volunteer / Teacher Directory**: Manage educators and subject allocations.
   - **NGO Institutional Profile**: Configure NGO Name, Trust Reg. No., Center Name, Address, and Director Signatory.
   - **Data Backup & Maintenance**: Export/Import JSON database backup, Clear Database, or optional demo loader.

3. **📥 Excel / CSV Bulk Data Import & Export**:
   - **Download Sample Template**: Download a ready-to-use CSV template to fill in Microsoft Excel.
   - **Bulk Import**: Paste rows or upload `.csv` to enroll 100+ students instantly.
   - **Export CSV**: 1-click export of complete student roster.

4. **👨‍🏫 Teacher Evaluation & Examination Panel**:
   - Select Class and Subject to record scores.
   - **Bulk Marks Upload via CSV/Excel**: Teachers can download a pre-filled class template, enter scores in Excel, and upload directly!
   - Auto-computes **CBSE 9-Point Grading Scale** (`A1`, `A2`, `B1`, `B2`, `C1`, `C2`, `D`, `E1`, `E2`) and Grade Points.

5. **📜 Official Templates with 1-Click Print / PDF**:
   - **Annual Academic Marksheet / Report Card Template**: Formal CBSE bilingual layout with NGO header, scholastic breakdown, co-scholastic traits, and Director signature.
   - **Transfer Certificate (TC) Template**: Official School Leaving Certificate with Admission No., Serial No., Conduct, and Reason for leaving.
   - **Student Identity Card (ID Badge) Template**: Clean vertical badge with student photo placeholder, blood group, emergency contact, and barcode.

6. **🌐 Public Student & Parent Result Portal**:
   - Parents and students can enter Roll Number or Admission Number to search, view, and print their official marksheet.

7. **⚡ Zero Demo Data by Default**:
   - Starts with a completely clean database (0 students, 0 marks).
   - Real data is populated only when uploaded or entered via the Admin panel.
